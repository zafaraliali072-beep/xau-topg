# xau.topg

A free, open-source trading utility PWA built for XAU/USD (Gold) traders — merges a trading journal with essential session tools, all in a single lightweight web app.

## Features

- **The Ledger** — built-in trading journal to log and review your trades
- **Essential Tools** — lot size calculator and pip value calculator (XAU/USD pip value: $10/standard lot)
- **4-Session Ribbon** — DST-aware visual ribbon showing Sydney, Tokyo, London, and New York session overlaps
- **Live News Tab** — ForexFactory economic calendar, mirrored via GitHub Actions for CORS-safe access
- **PWA-ready** — installable on desktop and mobile, works like a native app
